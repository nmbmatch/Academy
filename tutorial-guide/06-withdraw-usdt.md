# 06 Withdraw USDT

Send available USDT from NMB MATCH to an external wallet or exchange.

{% hint style="danger" %}
**Critical:** Crypto withdrawals can be irreversible. Verify the recipient address and blockchain network before confirming.
{% endhint %}

{% stepper %}
{% step %}
## Open Withdraw

Sign in to NMB MATCH and go to **Wallet**, **Assets**, or **Withdraw**.
{% endstep %}

{% step %}
## Select USDT

Choose **USDT** as the withdrawal asset.
{% endstep %}

{% step %}
## Get the Receiving Address

Open the destination wallet or exchange and copy its USDT deposit address.

Confirm which USDT network the receiving platform supports.
{% endstep %}

{% step %}
## Enter the Address and Network

Paste the destination address into NMB MATCH and select the matching network.
{% endstep %}

{% step %}
## Enter the Withdrawal Amount

Review:

* Withdrawal amount
* Network fee
* Minimum withdrawal, if applicable
* Final amount expected to arrive
{% endstep %}

{% step %}
## Complete Security Verification

Enter your secondary PIN and any other required security codes.
{% endstep %}

{% step %}
## Confirm the Withdrawal

Review all details one final time and submit the withdrawal.
{% endstep %}
{% endstepper %}

### Track the Transfer

Use your withdrawal history or transaction ID to monitor the transfer status.

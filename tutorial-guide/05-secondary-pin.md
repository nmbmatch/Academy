# 05 Secondary Pin

A secondary PIN can provide an extra layer of protection for sensitive account actions.

{% stepper %}
{% step %}
## Open Account Settings

Sign in to NMB MATCH and open **Profile**, **Security**, or **Account Settings**.

> 📷 **Screenshot placeholder:** Security settings page
{% endstep %}

{% step %}
## Find Secondary PIN

Select **Secondary PIN**, **Security PIN**, or the equivalent option.
{% endstep %}

{% step %}
## Create Your PIN

Enter a PIN that is difficult for others to guess.

Avoid using:

* Your birthday
* Repeating numbers
* Simple sequences such as 123456
* The same PIN used for other accounts
{% endstep %}

{% step %}
## Confirm the PIN

Re-enter the PIN and complete any email, mobile, or authenticator verification required.
{% endstep %}

{% step %}
## Store It Securely

Do not share your secondary PIN with friends, team members, support impersonators, or anyone contacting you privately.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**Security Reminder**

NMB MATCH support should never need your password, verification code, or full security PIN to assist you.
{% endhint %}

# 03 Deposit

Transfer USDT from your external wallet or exchange into your NMB MATCH account.

{% hint style="danger" %}
**Critical:** Always confirm the deposit address and supported network before sending. Blockchain transfers are usually irreversible.
{% endhint %}

{% stepper %}
{% step %}
## Open the Deposit Page

Sign in to NMB MATCH and open the **Wallet**, **Assets**, or **Deposit** section.
{% endstep %}

{% step %}
## Select USDT

Choose **USDT** as the deposit asset.
{% endstep %}

{% step %}
## Select the Correct Network

Choose the blockchain network shown as supported by NMB MATCH.

**Supported network:** `REPLACE_WITH_CURRENT_SUPPORTED_NETWORK`
{% endstep %}

{% step %}
## Copy Your Deposit Address

Copy the USDT deposit address displayed by NMB MATCH.

Double-check the first and last characters before continuing.
{% endstep %}

{% step %}
## Send USDT From Your Wallet or Exchange

Open your external wallet or exchange, choose **Withdraw** or **Send**, paste the NMB MATCH deposit address, and select the exact same network.
{% endstep %}

{% step %}
## Enter the Amount

Enter the amount of USDT you want to deposit and review:

* Destination address
* Network
* Withdrawal fee
* Amount to receive
{% endstep %}

{% step %}
## Confirm and Wait for Network Processing

Complete any required security verification. Your deposit may take time to appear depending on blockchain confirmations and platform processing.

{% hint style="info" %}
**Tip:** For a first transfer, consider sending a small test amount before transferring a larger balance.
{% endhint %}
{% endstep %}
{% endstepper %}
